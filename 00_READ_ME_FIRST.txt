INSTALLATION INSTRUCTIONS
=====================================================

OPTION A: Using Web Browser (EASIEST)

1. Go to GitHub.com and sign in
2. Click "+" icon > "New repository"
3. Name it: your-username.github.io
4. Make it PUBLIC
5. Click "Create repository"
6. In repository, click "Add file" > "Upload files"
7. Drag and drop the index.html file
8. Commit changes
9. Create images folder:
   - Click "Add file" > "Create new file"
   - Type: images/README.txt
   - Click "Commit changes"
10. Upload your photos to images/ folder
11. Go to Settings > Pages
12. Select "main" branch as source
13. Click Save
14. Wait 2-3 minutes
15. Your site is live at: https://your-username.github.io

OPTION B: Using Command Line (ADVANCED)

1. Install Git from https://git-scm.com
2. Open Terminal/Command Prompt
3. Run these commands:

   git clone https://github.com/your-username/your-username.github.io.git
   cd your-username.github.io
   
4. Copy index.html into this folder
5. Create images folder and add your photos
6. Run:

   git add .
   git commit -m "Add portfolio"
   git push origin main

=====================================================
GITHUB PAGES SETUP
=====================================================

1. Go to your repository on GitHub
2. Click "Settings" (gear icon)
3. Click "Pages" in left sidebar
4. Under "Build and deployment":
   - Source: Select "Deploy from a branch"
   - Branch: Select "main"
   - Folder: Select "/ (root)"
5. Click "Save"
6. Wait 1-2 minutes
7. You'll see: "Your site is live at https://your-username.github.io"

VERIFY DEPLOYMENT:
- Check for green checkmark next to "✓ GitHub Pages"
- If still building, wait a few more minutes
- Hard refresh browser: Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)

=====================================================
TROUBLESHOOTING
=====================================================

PROBLEM: Site shows 404 error
SOLUTION:
- Check URL is lowercase: https://your-username.github.io
- Wait 2-3 minutes for deployment
- Go to Settings > Pages > verify green checkmark
- Check repository name is correct: your-username.github.io

PROBLEM: Images not showing
SOLUTION:
- Check filenames match exactly (case-sensitive)
- Ensure images are in images/ folder
- Use .jpg format (not .JPG)
- Clear browser cache: Ctrl+Shift+Delete

PROBLEM: Changes not appearing
SOLUTION:
- Hard refresh: Ctrl+F5 or Cmd+Shift+R
- Clear cache and cookies
- Wait 1-2 minutes for GitHub rebuild
- Check Settings > Pages for deployment status

PROBLEM: Portfolio looks broken
SOLUTION:
- Check browser console for errors (F12 key)
- Test in different browser
- Verify all image filenames are correct
- Check index.html file was uploaded successfully
