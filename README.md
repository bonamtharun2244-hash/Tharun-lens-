EduTrain – Education & Training Chatbot

EduTrain is a modern, responsive Education and Training platform designed for students, teachers, professionals, job seekers, and anyone interested in learning new skills.

The website includes an interactive chatbot, education courses, training programs, student registration, certificates, and contact information.

How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click "index.html".
4. The website will open in your browser.

No server or installation is required for the basic version.

---

How to Deploy on GitHub Pages

Step 1: Create a Repository

1. Login to GitHub.
2. Create a new repository.
3. Give it a name such as:

edutrain-chatbot

4. Set the repository to Public.

Step 2: Upload Files

Upload the following files:

index.html
style.css
script.js
README.md

Step 3: Enable GitHub Pages

1. Open your repository.
2. Go to Settings.
3. Select Pages.
4. Under Build and deployment, choose:

Source: Deploy from a branch
Branch: main
Folder: / (root)

5. Click Save.

After a few minutes, your website will be available through GitHub Pages.
